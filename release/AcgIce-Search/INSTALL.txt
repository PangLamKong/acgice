========================================
  AcgIce 多语言聚合搜索引擎 - 安装说明
========================================

【环境要求】
- PHP 7.3 及以上（支持 PHP 8.x）
- 开启 cURL 扩展
- 开启 mbstring 扩展

【快速启动】
方法一：PHP内置服务器（开发测试用）
  cd AcgIce-Search
  php -S 127.0.0.1:8080 index.php
  然后访问 http://127.0.0.1:8080/

方法二：Nginx/Apache（生产环境）
  将整个目录放到网站根目录
  配置伪静态（参考 .htaccess）

【功能说明】
- 5个搜索引擎聚合：Bing、百度、DuckDuckGo、搜狗、360搜索
- 网站favicon缩略图显示
- 官网标识
- 中文站点名显示
- 搜索结果去重排序
- 搜索结果缓存

【配置文件】
- config.php：网站配置
- www/config.php：ThinkPHP配置
- www/database.php：数据库配置（如需数据库）
